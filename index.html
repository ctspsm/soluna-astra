Zero Breaking Changes — ปรับชื่อใหม่โดยไม่กระทบสคริปต์เดิม

04 · SCALE

Distributed Sharding (SHA-256)

แบ่งโหลดเคสทดสอบขนาดใหญ่ (2,000+ เคส) ออกเป็นหลาย Worker ด้วยการ Hash Case ID เคสเดิมจะอยู่ Worker เดิมเสมอ และรวมผลลัพธ์ผ่านคำสั่ง merge

./soluna run my-target orders --shard 1/20
✦
05 · SAFETY

Receipt-Driven Clean Up

ป้อนข้อมูลทดสอบ (Seed) พร้อมออกใบเสร็จ (Receipt) ระบุ IDs ชัดเจน เมื่อตรวจเสร็จสั่ง Clean ลบคืนฐานข้อมูลเดิมได้สะอาดหมดจด 100%

./soluna clean my-target --receipt receipts/run.json --confirm
